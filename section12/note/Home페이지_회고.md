## Home 컴포

- 왜 Home 컴포넌트에서 날짜값을 state로 관리하면서 Header에 전달할까?
  - Header를 다양한 용도로 재사용하기 위해 설계 되었기 때문. 다른 UI는 연-월 정보가 아님.
  - 고로 Home 컴포 전용 데이터이고 동적인 데이터기에 state 처리이고 state 처리는 리렌더링해서 UI에 가시해야 하기 때문임.
  - 즉 이벤트가 발생해 UI에 변경사항이 적용되야 하는것들은 state or reducer로 적용 필요
  - 그리고 각 버튼의 이벤트 헨들러도 Home 컴포에 있어야 하는것은 Home 컴포만의 기능을 Header에 적용하는것이기에 그러함.

- piovotDate는 왜 state?
  - piovotDate는 해당 페이지에서 보여줄 일기데이터를 월별로 보여주기 위한 값임
  - 고로 사용자가 보고자 하는 달이 바뀌면 그에 맞는 일기 데이터를 보여줘야하고 날짜는 동적이고 리렌더링이 필수 일수 밖에 없기에 state로 처리.

- 컴포넌트 밖의 함수와 내부의 함수는 무슨 기준이지?
  - 문제는 없고 가독성과 재사용성이라고 함.
  - 앞으로 복잡한 로직을 가진 함수가 매개변수로 값을 전달 받을수 있으면 컴포외부에 선언하는게 더 좋다고함.
  - 해서 Home 컴포가 리렌더링 될때 마다 getMonthlyData() 실행됨.
